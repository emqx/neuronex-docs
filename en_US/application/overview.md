# Application Integration

Connect data collected and processed by EMQX Neuron to cloud platforms, message queues, databases, and other external systems through:

- [Northbound applications](../configuration/north-apps/north-apps.md): MQTT, Sparkplug B, Kafka, WebSocket, and more
- [Data processing sinks](../streaming-processing/sink/sink.md): write rule results to external systems

To generate Python extension functions from natural language, see the [AI-generated Python Plugin Guide](../best-practise/llm-portable-plugin.md).

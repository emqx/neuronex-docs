# 应用集成

将 EMQX Neuron 采集和处理后的数据对接到云平台、消息队列、数据库等外部系统，主要通过：

- [北向应用](../configuration/north-apps/north-apps.md)：MQTT、Sparkplug B、Kafka、WebSocket 等
- [数据处理 Sink](../streaming-processing/sink/sink.md)：将规则结果写入外部系统

如需用自然语言生成 Python 扩展函数，见 [AI 生成 Python 插件最佳实践指南](../best-practise/llm-portable-plugin.md)。

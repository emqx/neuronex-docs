# 批量配置与迁移

单个驱动、单个点位的配置方式见[添加南向驱动](./south-devices/south-devices.md)与[组与点位](./groups-tags/groups-tags.md)。实际项目往往是几十上百个同型号设备、单节点上千个点位，逐个录入不现实。本节介绍四种批量手段。

## 选择方式

| 场景 | 方式 |
| --- | --- |
| 单个节点内有成百上千个点位 | [批量点位配置](./import-export/import-export.md)（Excel 导入导出） |
| 已配好的驱动整体复制一份，只改连接参数 | [驱动复制](#驱动复制) |
| 备份整机配置，或迁移到另一个实例 | [南向设备导入导出](#南向设备导入导出) |
| 从 KEPServerEX、Litmus Edge 等平台迁移 | [驱动转换工具](./driver-migration-tool.md) |

## 驱动复制

在**南向设备**页的驱动卡片上点击 **复制**，生成一个包含原节点全部配置、组和点位的新节点。复制后需要修改新节点的连接参数（如 IP 地址、站点号），否则两个节点会连向同一台设备。

## 南向设备导入导出

在**南向设备**页右上角点击 **导出**，将当前实例的全部南向驱动配置与点位导出为 JSON 文件；点击 **导入** 可将该文件恢复到同一实例或另一个实例。

常见用途：

- **配置备份**：升级或迁移前留存一份完整配置。
- **环境复制**：在测试环境调通后，整体导入到现场实例。
- **主备同步**：主备模式下保持两台实例的数采配置一致，见[主备模式](../best-practise/master-backup.md)。

::: tip
[驱动转换工具](./driver-migration-tool.md)的输出文件同样通过此处导入。
:::

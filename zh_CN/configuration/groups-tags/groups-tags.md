# 配置采集组与点位

点位归属到采集组。每个组有独立的采集频率。要让设备和 EMQX Neuron 通信，先为南向驱动添加组和点位。组和点位创建完成后，可在数据监控中查看点位实时值。

## 在设备节点中创建组

同一组内的点位按相同频率采集和上报。

点击新添加的设备节点进入组列表，点击 **创建组**。

* **名称**：组名称，例如 `group-1`。
* **时间间隔**：该组点位的采集和上报频率，单位毫秒。`100` 表示每 100ms 采集一次，整组点位上报一次。

## 在组中添加点位

添加需要采集的设备点位，包括地址、属性、数据类型等。

点击组中的 **点位列表**，进入点位列表页，再点击 **添加点位**。

![tags-add](../south-devices/assets/tags-add.png)

* **名称**：点位名称，例如 `tag1`。
* **属性**：下拉选择 read、write、subscribe、static，可多选。见 [点位属性](#点位属性)。
* **类型**：数据类型，例如 int16、uint16、int32、uint32、float、bit。
* **地址**：不同驱动的地址规范不同。以 Modbus 为例，`1!40001` 中 `1` 为站点号，`40001` 为寄存器地址。详见各南向驱动页。
* **乘系数**：默认不填；属性为 read 时，`设备原始值 * 乘系数 = 上报值`。
* **偏移量**：默认不填；属性为 read 时，`设备原始值 + 偏移量 = 上报值`。点位含 write 时不可用。仅支持数值和浮点类型。
* **精度**：类型为 `float` 或 `double` 时配置，范围 0～17。
* **描述**：默认不填。

### 点位属性

点位包括 **read**、**write** 和 **subscribe**。

- read / write 分别用于读数据和写数据。
- subscribe 仅在数据变化时向北向应用发送消息。例如默认值为 0，改为 2 时发送一条消息。在 MQTTX 中订阅后类似下图：

  ![mqttx_subscribe](../south-devices/assets/mqttx_subscribe.png)

### 点位精度

类型为 `float` 或 `double` 时配置精度，范围 0～17：

- 未设置精度时，默认保留 5 位小数。
- 从小数第二位起，若连续两位为 `00` 或 `99`，则四舍五入。例如 `1.02990` 显示为 `1.03`，`1.80012` 显示为 `1.8`。
- 设置了精度后，EMQX Neuron 不再四舍五入。

## 测试连接

点位创建完成后，设备工作状态应为 **运行中**，连接状态应为 **已连接**。若仍为 **未连接**，在 EMQX Neuron 运行环境执行：

```bash
$ telnet <设备 IP> <端口>
```

:::tip
确认设备配置中的 IP 与端口正确，并关闭防火墙。
:::

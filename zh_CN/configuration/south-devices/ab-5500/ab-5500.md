# Allen-Bradley ControlLogix 5500

Allen-Bradley ControlLogix 5500 适用于 Allen-Bradley ControlLogix 5500 系列 PLC 设备，其中包括 Allen-Bradley ControlLogix 4 slot chassis 型号PLC。

通用配置步骤见[添加南向驱动](../south-devices.md)与[组与点位](../../groups-tags/groups-tags.md)。

## 添加驱动

在 **数据采集 → 南向设备** 页点击 **添加设备**，驱动类型选择 **Allen-Bradley ControlLogix 5500**。

## 连接参数

点击驱动卡片进入**设备配置**页填写：

| 字段 | 说明                  |
| ---- | --------------------- |
| PLC IP 地址 | 设备 IP 地址            |
| PLC 端口 | 设备端口，默认为 44818 |
| CPU槽号 | CPU 槽号，默认为 0     |

## 点位配置

以下为本驱动支持的数据类型与地址格式。

### 数据类型

* INT8
* UINT8
* INT16
* UINT16
* INT32
* UINT32
* INT64
* UINT64
* FLOAT
* DOUBLE
* BOOL
* BIT
* STRING
* WORD
* DWORD
* LWORD

### PLC 数据地址

>  TAG NAME

使用 PLC 软件连接到 PLC，PLC 上点位的名称即为 EMQX Neuron 中点位地址。

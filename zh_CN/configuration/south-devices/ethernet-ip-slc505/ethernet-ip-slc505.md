# Allen-Bradley SLC 5/05

Allen-Bradley SLC 5/05 驱动通过 EtherNet/IP 封装的 PCCC 协议，直连 SLC 5/05 CPU 的以太网接口读写 PLC 数据。

通用配置步骤见[添加南向驱动](../south-devices.md)与[组与点位](../../groups-tags/groups-tags.md)。

## 添加驱动

在 **数据采集 → 南向设备** 页点击 **添加设备**，驱动类型选择 **Allen-Bradley SLC 5/05**。

使用前请确认：

- CPU 固件支持 EtherNet/IP，Neuron 所在主机能够访问 PLC 的以太网接口。
- 本驱动仅支持以太网直连，不支持通过背板、DH+ 或 DF1 网关路由。
- 不支持 TCP 2222 端口使用的传统 CSP/PCCC 协议。
- 许可证已包含 SLC 5/05 驱动授权；仅有 MicroLogix 1400 或 AB5000 驱动授权不能替代。

## 连接参数

点击驱动卡片进入**设备配置**页填写：

| 字段 | 说明 |
| ---- | ---- |
| PLC IP地址 | SLC 5/05 CPU 以太网接口的 IPv4 地址 |
| PLC端口 | EtherNet/IP TCP 端口，默认为 44818，范围为 1～65535 |
| 通讯超时 | TCP 收发超时时间，单位为毫秒，默认为 3000，范围为 100～60000 |

例如，设备 IP 地址为 `192.168.1.10` 时，对应的连接参数为：

```json
{
  "host": "192.168.1.10",
  "port": 44818,
  "timeout": 3000
}
```

## 点位配置

### 数据类型

- INT16
- UINT16
- WORD
- FLOAT
- BIT
- BOOL
- STRING

整字读取支持 `INT16`、`UINT16` 或 `WORD`。位读取支持 `BIT` 或 `BOOL`，地址必须包含数字位号或命名状态位；例如 `B3:0` 是整字地址，不能直接配置为 `BOOL`。

### PLC 数据地址

地址不区分大小写，使用 PLC 数据文件寻址。

普通数据文件使用 `文件标识文件号:元素号`，例如 `N7:0`。位地址在整字地址后追加 `/位号`，位号范围为 0～15。

| 文件类型 | 文件标识 | 地址示例 | 数据类型 |
| -------- | -------- | -------- | -------- |
| 输出映像 | O | `O:2`、`O:2.1`、`O:2.1/3` | 整字或位 |
| 输入映像 | I | `I:1`、`I:1.0`、`I:1.0/5` | 整字或位 |
| 状态 | S | `S:1`、`S2:1`、`S:1/15` | 整字或位 |
| 二进制 | B | `B3:0`、`B3:0/5`、`B3/17` | 整字或位 |
| 整数 | N | `N7:0`、`N7:0/15` | 整字或位 |
| 浮点数 | F | `F8:0` | FLOAT |
| 定时器 | T | `T4:0`、`T4:0.PRE`、`T4:0.ACC`、`T4:0/EN` | 整字或状态位 |
| 计数器 | C | `C5:0`、`C5:0.PRE`、`C5:0.ACC`、`C5:0/DN` | 整字或状态位 |
| 控制 | R | `R6:0`、`R6:0.LEN`、`R6:0.POS`、`R6:0/EN` | 整字或状态位 |
| 字符串 | ST | `ST9:0`、`ST9:0.LEN` | 整条字符串为 STRING，LEN 为整字 |
| ASCII | A | `A10:0`、`A10:0/3` | 整字或位，不自动转换为文本 |

- I/O 地址使用 `I:槽位.字子元素` 或 `O:槽位.字子元素`，省略字子元素时为 0。槽位和字子元素应与 PLC 工程一致，驱动不假定每个 I/O 模块有固定的字数。
- 状态文件固定为文件 2，`S:1` 与 `S2:1` 等价。
- 二进制文件支持线性位寻址，`B3/17` 表示文件 B3 的第 17 位，与 `B3:1/1` 等价。

### 定时器、计数器与控制成员

T、C、R 的每条记录占用 3 个 16 位字。

| 文件类型 | 第 1 个字 | 第 2 个字 | 第 3 个字 | 命名状态位及位号 |
| -------- | -------- | -------- | -------- | ---------------- |
| T | 状态字 | PRE | ACC | EN=15、TT=14、DN=13 |
| C | 状态字 | PRE | ACC | CU=15、CD=14、DN=13、OV=12、UN=11、UA=10 |
| R | 状态字 | LEN | POS | EN=15、EU=14、DN=13、EM=12、ER=11、UL=10、IN=9、FD=8 |

命名状态位支持 `.` 和 `/` 两种形式，例如 `T4:0.DN` 与 `T4:0/DN` 等价，数据类型均为 `BIT` 或 `BOOL`。成员字还可以按数字位号读取，例如 `T4:0.ACC/0`。

### 字符串

使用 `ST9:0` 和 `STRING` 类型读写整条字符串，不需要追加字符串长度或字节序后缀。SLC 字符串记录由 16 位 LEN 和 82 个字符字节组成，驱动自动处理字内字符顺序，按 LEN 返回内容，支持空字符串，最大内容长度为 82 字节。

使用 `ST9:0.LEN` 和 `UINT16` 等整字类型可单独读写长度，写入范围为 0～82；单独修改 LEN 不会更新字符内容。LEN 超出范围或响应数据不完整时会报错，不会静默截断。

### 写入数据

输出映像（O）、二进制（B）、整数（N）、浮点数（F）、定时器（T）、计数器（C）、控制（R）、字符串（ST）和 ASCII（A）文件支持写入，实际可写权限由 PLC 决定。

- 整字使用 `INT16`、`UINT16` 或 `WORD` 写入，浮点数使用 `FLOAT`。
- 位使用 `BIT` 或 `BOOL` 写入。`BIT` 值只能为 0 或 1；驱动通过 PCCC 掩码写仅修改目标位，保留同一字中的其他位，不采用先读后写整字的方式。
- 定时器、计数器和控制记录按成员写入，例如 `T4:0.PRE`、`C5:0.ACC`、`R6:0.POS`；裸记录地址只写状态字，不覆盖整条结构。
- 字符串写入同时更新 LEN 和字符内容，超长字符串直接报错，不会截断。

将以下点位配置为**读写**后，可在数据监控页下发写入值，并在后续采集周期核对读回值：

| 地址 | 数据类型 | 写入示例 |
| ---- | -------- | -------- |
| `N7:0` | INT16 | `111` |
| `F8:0` | FLOAT | `12.5` |
| `B3:0/5` | BOOL | `true` |
| `ST9:0` | STRING | `hello` |

写入前请确认 PLC 应用允许修改目标数据。输出映像、记录成员和状态位可能被 PLC 程序在扫描周期中重新更新。写入超时或连接断开时，驱动不会自动重放该写请求；应先核对 PLC 当前值，再决定是否重新写入。

### 点位配置示例

以下点位的属性均设置为**读**，文件号和元素号需按实际 PLC 工程调整。

| 地址 | 数据类型 | 说明 |
| ---- | -------- | ---- |
| `O:2.1` | WORD | 输出映像槽位 2 的字子元素 1 |
| `I:1.0/5` | BOOL | 输入映像槽位 1、字子元素 0 的第 5 位 |
| `S2:1` | WORD | 状态文件 2 的元素 1 |
| `B3:0` | WORD | 二进制文件 3 的元素 0，读取整个 16 位字 |
| `B3/17` | BIT | 二进制文件 3 的线性位 17，即 `B3:1/1` |
| `N7:0` | INT16 | 整数文件 7 的元素 0 |
| `N7:0/15` | BOOL | 整数文件 7 的元素 0 的第 15 位 |
| `F8:0` | FLOAT | 浮点文件 8 的元素 0 |
| `T4:0.PRE` | INT16 | 定时器 0 的预设值 |
| `T4:0.ACC` | INT16 | 定时器 0 的累计值 |
| `T4:0/DN` | BOOL | 定时器 0 的完成标志 |
| `C5:0.ACC` | INT16 | 计数器 0 的累计值 |
| `R6:0.POS` | UINT16 | 控制记录 0 的位置值 |
| `ST9:0` | STRING | 字符串文件 9 的元素 0 |
| `ST9:0.LEN` | UINT16 | 字符串文件 9 的元素 0 的长度 |
| `A10:0` | WORD | ASCII 文件 10 的元素 0，以原始字值返回 |

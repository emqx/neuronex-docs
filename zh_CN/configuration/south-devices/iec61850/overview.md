# IEC61850

IEC61850 是一种国际通信标准协议，通过对设备的一系列规范化，达到了全站的通讯统一。 IEC61850 广泛应用于电力行业。

通用配置步骤见[添加南向驱动](../south-devices.md)与[组与点位](../../groups-tags/groups-tags.md)。

MMS 报文规范运用在 IEC61850 标准站控层和间隔层之间，MMS 通过对实际设备进行面向对象建模方法，实现了网络环境下不同制造设备之间的互操作。

IEC61850 驱动用于对 IEC61850 服务器的读/写，目前支持 MMS 协议的访问。

## 添加驱动

在 **数据采集 → 南向设备** 页点击 **添加设备**，驱动类型选择 **IEC61850**。

## 连接参数

点击驱动卡片进入**设备配置**页填写：

|  参数    | 说明                       |
| -------- | -------------------------- |
| **设备 IP 地址** | 目标设备 IP              |
| **设备端口** | 目标设备端口号，默认为 102 |
| **总召唤间隔** | 设备发送总召唤的间隔，为 0 时关闭总招，单位秒 |

## 点位配置

以下为本驱动支持的数据类型与地址格式。

IEC61850 驱动只支持通过导入 SCL 文件自动添加组与点位，SCL 文件中的 Report 块生成可读性数据组，根据引用的 DataSet 生成点位；根据 FC 为 CO、SP、SG 的数据生成可写点位，可写点位单独在一个 Control 组中。

IEC61850 驱动根据行业规范，单独定义了数据上报结构，在每个数据点位中，除了点位值外，还包含 timestamp、quality 字段。

```json
{
 "timestamp": 1647497389075,
 "node": "iec61850",
 "group": "grp1",
 "tags": [{
   "name": "tag1",
   "value": 123,
   "q": 3,
   "t": 129401039041
  },
  {
   "name": "tag2",
   "value": 123,
   "q": 3,
   "t": 129401039088
  }
 ]
}
```

::: tip 注意

由于 IEC61850 驱动采用特殊数据上报结构，所以在北向驱动选择数据格式时，需要对应选择 **Tags-format** 格式。
:::

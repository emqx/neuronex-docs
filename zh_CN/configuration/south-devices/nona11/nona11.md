# NON A11

非 A11 驱动适用于非 A11 设备，驱动支持 client 和 server 模式对接设备。目前驱动支持UINT16/INT16/UINT32/INT32/FLOAT/STRING 数据类型，支持用户自定义指令读取数据。

通用配置步骤见[添加南向驱动](../south-devices.md)与[组与点位](../../groups-tags/groups-tags.md)。

## 添加驱动
在 **数据采集 → 南向设备** 页点击 **添加设备**，驱动类型选择 **NON A11**。

## 连接参数

点击驱动卡片进入**设备配置**页填写：

| 字段     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 连接模式 | 驱动程序连接到设备的方式，默认为 client，即把 EMQX Neuron 作为客户端使用 |
| IP 地址  | 当 EMQX Neuron 作为客户端使用时，host 指远程设备的 IP。当 EMQX Neuron 作为服务端使用时，host 指 EMQX Neuron 在本地使用的 IP，默认可填写 0.0.0.0 |
| 端口号     | 当 EMQX Neuron 作为客户端使用时，post 指远程设备的 TCP 端口。当 EMQX Neuron 作为服务端使用时，host 指 EMQX Neuron 在本地使用的 TCP 端口。 |
| 站点号 | 站点号 |
| 连接超时时间 | 连接超时时间，单位为毫秒 |
| 指令发送间隔 | 发送读指令时间间隔，单位为毫秒 |

## 点位配置

以下为本驱动支持的数据类型与地址格式。

### 数据类型

* INT16
* UINT16
* INT32
* UINT32
* FLOAT
* STRING

### 地址格式

> SITE ! COMMAND ! OFFSET[.LEN]

### 地址示例

| 地址    | 数据类型           | 说明                        |
| ------- | ------------------ | --------------------------- |
| 1!1!10.20 | string             | 站点1，指令1，偏移10，字符串长度20 |
| 1!12!1    | uint16/int16       | 站点1，指令12，偏移1               |
| 1!20!32   | uint32/int32/float | 站点1，指令20，偏移32              |
